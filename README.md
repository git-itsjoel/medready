# MedReady - Hospital Medicine Availability Tracker

MedReady is a web-based application designed to help patients check the availability of medicines in local hospitals in real-time. It provides a centralized platform for inventory visibility, reducing unnecessary travel during emergencies.

## Features

*   **Public Search**: Search for medicines by name, hospital, or category (including custom categories).
*   **Real-time Availability**: See if a medicine is "Available" or "Out of Stock".
*   **Hospital Auto-Complete**: Smart suggestions when typing hospital names.
*   **Staff Portal**: Secure login for hospital staff to manage their specific inventory.
*   **Super Admin**: Hidden portal to register new hospitals and staff.
*   **Responsive Design**: Modern, lavender-themed UI that works on desktop and mobile.

## Technologies Used

*   **HTML5 & CSS3**: Custom styling with a modern glassmorphism aesthetic.
*   **JavaScript (Vanilla)**: Core logic for DOM manipulation and Mock API.
*   **LocalStorage**: Simulates a backend database for persistent data during the session.
